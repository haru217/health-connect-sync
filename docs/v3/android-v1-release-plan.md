# Health OS Android v1.0 リリースプラン

**作成日**: 2026-03-18
**目標リリース**: 2026-04-14（月）Play Store公開申請
**ステータス**: CEO承認済み

## 1. プロダクト概要

Health Connectの全データを統合し、AIアシスタント「はる」が健康アドバイスを提供するAndroidネイティブアプリ。

### ターゲットユーザー
スマートデバイス（スマートウォッチ・フィットネストラッカー）を装着している層

### マネタイズ
- **モデル**: 回数制限型（C型）フリーミアム
- **Free**: データ同期・閲覧・グラフ、AIレポート月3回、食事分析月5回
- **Pro（月額未確定）**: AIレポート無制限、食事分析無制限
- **価格帯候補**: ¥480 / ¥680 / ¥980（リリース直前に確定）

### 粗利構造（1万ユーザー、600 Pro想定）
- LLMコスト: ~¥18/Pro user/月（ハイブリッドモデル）
- インフラ: ~¥6,750/月（Cloudflare + Firebase無料枠内）
- Google Play手数料: 15%
- **粗利率: 76〜80%**

## 2. アプリ構成

### ボトムタブ（4タブ）

| タブ | 内容 |
|------|------|
| ホーム | はるのAIレポート（日次/週次/月次/カスタム） |
| 食事 | カメラ撮影→Gemini画像分析、手動入力、サプリ、薬の登録 |
| データ | Health Connectの全データをグラフ表示（ないものは非表示） |
| マイページ | プロフィール編集・目標設定・サブスク管理・アプリ設定・ログアウト |

### AI構成
- 「はる」1人に統一（旧3専門家ユウ/サキ/マイは廃止）

### オンボーディング
1. アカウント作成（Firebase Auth）
2. プロフィール入力（年齢・性別・身長・目標）
3. Health Connect権限許可

## 3. 技術スタック

| レイヤー | 技術 |
|---------|------|
| Android UI | Jetpack Compose |
| 認証 | Firebase Auth |
| 課金 | RevenueCat + Google Play Billing |
| 同期 | WorkManager（自動バックグラウンド同期） |
| バックエンドAPI | Cloudflare Workers + D1（既存） |
| LLM | Claude Haiku（週次/月次）+ Gemini Flash（日次/食事分析） |
| Health Connect | AndroidX Health Connect Client |

## 3.1 エージェント体制

| エージェント | 役割 | 呼び出し方 |
|------------|------|-----------|
| **Claude**（CTO） | 設計・仕様策定・タスク分解・レビュー・調整 | 本セッション |
| **Codex** | 実装（Android/バックエンド両方） | MCP（mcp__codex__codex）で直接指示 |
| **Gemini** | UIデザイン・ストア素材・デザイン相談 | CLI（gemini -p "..." -y）で直接呼び出し |

※Codexは廃止。Codex MCPで一元化。
※requestファイル経由のワークフローは廃止。Claude→Codex/Geminiの直接指示に移行。

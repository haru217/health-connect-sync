# Request: レポート表示改善

- Date: 2026-03-18
- Owner: Codex
- Status: `done`
- Phase: H4
- Priority: 中

## 背景

レポート詳細の箇条書きが段落に埋もれて読みにくく、ホームから週次履歴へ戻る導線も消えていました。追加レポートも直近1件しか見えず、比較しづらい状態でした。

## 変更方針

1. レポート詳細では行ごとに整形し、箇条書き記号を外して読みやすくする。
2. ホーム下部に週次履歴への導線を戻す。
3. 追加レポートは最新3件を並べて、直近の内容をすぐ選べるようにする。

## 完了条件

1. 箇条書き行が通常文に埋もれず、太字表現も維持される。
2. ホーム最下部から履歴一覧へ進める。
3. 追加レポートが0件なら何も出さず、ある場合は最新3件を表示する。
4. `npx tsc --noEmit` が通る。
